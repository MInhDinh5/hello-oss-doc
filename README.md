# Dự án Hello OSS

## Mô tả

Hello OSS là một chương trình C đơn giản dùng để thực hành phát triển phần mềm mã nguồn mở.

## Mục tiêu

- Làm quen với Git và GitHub.
- Thực hành quản lý mã nguồn.
- Tìm hiểu cách xây dựng tài liệu cho dự án mã nguồn mở.

## Hướng dẫn Cài đặt & Sử dụng

### Yêu cầu

- Trình biên dịch GCC.
- Git.
